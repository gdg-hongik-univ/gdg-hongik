# GDG Changeset 작성 연결

먼저 [공유 스킬 원본](../../../.agents/skills/gdg-changeset/SKILL.md)을 읽고 그 절차를 따라요.
사용자가 지정한 비교 기준과 변경 범위를 원본 절차에 적용해요.
연결 파일에 작성 규칙을 복제하지 않아요.
